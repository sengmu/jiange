# 剑阁手游 UI 重制 · 设计规格 v1（2026-11-15）

配套设计图（同目录，均为 1672×941、横屏 16:9，按 1920×864 逻辑画布解读）：

- `A_battle_hud.png` — 方向 A「青铜墨金·三国战卷」战斗 HUD
- `A_hero_select.png` — 方向 A 选将界面
- `B_battle_hud.png` — 方向 B「明玉暖陶·清爽手游」战斗 HUD
- `B_shop_panel.png` — 方向 B 商店面板（一级装备店）

两方向共用同一布局骨架（简报定版）：顶栏细条（左：封印核血条+波次；中：事件横幅；右：小地图+金币+菜单）／左下摇杆／右下技能集群／底部中 6 格背包条／左侧英雄头像卡。下文尺寸均为 1920×864 逻辑像素口径，触控热区一律 ≥64、间距 ≥10。

## 方向 A「青铜墨金·三国战卷」

气质：沉稳厚重、策略感强；深墨漆器面板 + 古铜金描边 + 绢帛暗纹，像展开的军机战卷。

### 配色（HEX，按设计图取色）

| 角色 | HEX | 用途 |
|---|---|---|
| 主色·墨黑 | `#171208` / `#1E1811` | 面板底、顶栏底、背包条底 |
| 主色·古铜金 | `#C9A227`（高光 `#E8C766`，暗部 `#8A6A2F`） | 边框、角花、分隔线、标题字 |
| 辅色·蜀红 | `#A62B1F`（亮 `#C8402A`） | 事件横幅卷轴、选中描边、旗帜呼应 |
| 辅色·紫晶 | `#9B4DFF`（辉光 `#C07FFF`） | 封印核血条、技能图标底、选中光晕 |
| 文字·绢黄 | `#F2E3BC` | 主文字、数字 |
| 文字·次级 | `#B8A678` | 次级标签 |
| 血条绿 | `#57C84B` | 英雄血条 |
| 经验金 | `#E0A92E` | 经验细条 |

### 面板材质

哑光黑漆木板 + 1–2px 古铜金线边框 + 四角铜质回纹角花；大面板内衬极暗绢帛云纹（低对比、不抢字）；横幅类控件做成卷轴形（两端铜轴头）。

### 字体层级（相对大小，1920 宽画布）

- 标题（选择武将/开始守城）：44–48，描边深褐
- 关键数字（血量/金币/波次）：36–40
- 卡片名/按钮字：30–34
- 正文/属性行：26–28
- 辅助小字下限：22（再小不入常驻 HUD）

### 关键控件尺寸

- 主技能圆钮：Ø 148（图面约占屏宽 13%），带紫色冷却扫层 + 秒数大字
- 小圆钮（修复/下一波）：Ø 84，竖列置于主技能钮左上/右侧
- 摇杆：Ø 168 半透明铜环，按下才提亮
- 顶栏高：64；封印核血条宽约 300、厚 12
- 英雄头像卡：约 320×116（头像 96×96 + 等级角标）
- 背包格：76×76，间距 10
- 选将卡：约 208×124（6 列），头像区约占卡高 62%；锁定卡整体压暗至约 45% 亮度 + 铜锁徽居中
- 开始守城金钮：约 300×88；关闭钮：72×72 方形铜框

### 与战场呼应点

- 紫晶辉光直接取自左侧基地封印核：血条、技能底色、选中光晕同紫，形成「核—UI」一条视觉线。
- 蜀红只用在横幅与选中态，与战场红旗同色系，不另起红。
- 古铜金呼应门楼铜件与黄昏暖光，墨黑底压住黄昏高亮背景，保证户外可读。

### Godot 落地（九宫格/图集）

- 面板九宫格：墨黑面板 1 张（边 48，含金边+角花，角花须进不可拉伸区）、卷轴横幅 1 张（左右轴头固定宽、中段横拉）、金钮 1 张（横拉）。
- 图集：一张 2048 图集装全部图标（金币/波次/技能/背包/任务/系统/属性小图标）+ 品质边框 4 色；头像单独图集（22 张、256²）。
- 血条/经验条用纯色 StyleBoxFlat 或 1px 拉伸图，不进图集。

## 方向 B「明玉暖陶·清爽手游」

气质：清爽亲和、主流手游感；奶白厚圆角面板 + 暖陶土 + 草绿 + 天蓝，圆润饱满、可读性优先。

### 配色（HEX，按设计图取色）

| 角色 | HEX | 用途 |
|---|---|---|
| 主色·奶白 | `#FFF6E3`（阴影面 `#F3E3C2`） | 面板底、顶栏胶囊、背包条底 |
| 主色·暖陶土 | `#C96F4A`（深 `#A34E2C`） | 店名牌匾、事件横幅、关闭钮 |
| 辅色·草绿 | `#57B84C`（深 `#3E9440`） | 购买钮、血条、属性增量字 |
| 辅色·天蓝 | `#4FB3E8`（深 `#2E86C8`） | 技能钮、摇杆、经验条 |
| 辅色·紫晶 | `#9B4DFF` | 紫品质边、封印核图标（与战场焦点同色） |
| 文字·深褐 | `#4A3220` | 主文字、数字（压奶白底，高对比） |
| 金币金 | `#F5B921` | 金币图标与价格数字底衬 |

### 面板材质

奶白陶土板 + 大圆角（半径 28–36）+ 底部一条陶土色软阴影边；牌匾类控件做成陶土浮雕牌（内阴影+描边字）；无金属边框、无暗纹，靠色块分层。

### 字体层级（相对大小，1920 宽画布）

- 标题（装备店/敌军来袭）：42–46，圆体粗字 + 深色描边
- 关键数字（金币/价格/血量）：36–40
- 物品名/按钮字：32–34
- 属性增量：30（草绿粗体）
- 辅助小字下限：22

### 关键控件尺寸

- 主技能圆钮：Ø 148（天蓝圆盘 + 白色冷却弧 + 秒数胶囊）
- 小圆钮（修复/下一波）：Ø 84，竖列
- 摇杆：Ø 168 半透明天蓝圆盘，静止低透明
- 顶栏胶囊高：64；小地图约 200×150 圆角卡
- 英雄头像卡：约 316×112（圆形头像 Ø 88 + 等级圆徽）
- 背包格：76×76 圆角格，品质色边 4px（白 `#D8D8D8`／绿 `#57B84C`／蓝 `#4FB3E8`／紫 `#9B4DFF`）
- 商店行：高 104；物品图标格 88×88；购买钮约 176×68 大圆角
- 关闭钮：Ø 76 陶土红圆钮，固定面板右上、外凸半个钮身

### 与战场呼应点

- 陶土色取自中央土路与黄昏暖光，草绿取自冷灰绿草地，天蓝取自暮空——UI 像从战场里长出来的色板，明亮但不另起世界。
- 封印核图标与紫品质边保留紫晶色，焦点色不丢。
- 蜀旗红收进横幅与旗帜小图标，不大面积用红，避免与陶土撞色。

### Godot 落地（九宫格/图集）

- 面板九宫格：奶白圆角面板 1 张（边 56，圆角进不可拉伸区）、陶土牌匾 1 张（横拉）、绿购买钮/陶土钮各 1 张（横拉）。
- 图集：一张 2048 图集装全部圆润图标 + 品质边框 4 色（边框做成九宫格小图、按格尺寸套用）；物品图标单独图集（128²/格）。
- 圆钮类（技能/摇杆/关闭）用整图 TextureButton，不走九宫格；冷却扫层用 shader 或扇形 Polygon2D，别用粒子。

## 移动性能注意（两方向共同）

- 禁：全屏实时模糊（BackBufferCopy+blur）、大面积半透明叠层超过 2 层、粒子型 UI 动效、逐帧脚本改控件尺寸/位置。
- 只许廉价动效：边框流光（shader 时间参数）、冷却扫层、数字跳字、面板 0.18s 位移+透明度入场。
- UI 纹理总量控制在 2 张 2048 图集 + 头像/物品图集内；面板全部九宫格复用，不给每个面板单独出图。
- 帧率/画质入口收进系统菜单（顶栏菜单钮内），不常驻 HUD——设计图已按此执行。
- 安全区：所有常驻控件内缩至安全区内（图面已留边），Godot 侧继续走既有 `_apply_safe_area()` 口径用 offset 定位。

## 图面与现行数据的已知出入（定方向后、实现前对齐，不影响挑皮肤）

- A 选将图卡面名单为占位示意（如黄盖、孟获），实现时以现行 22 英雄数据表为准；头像为风格占位肖像。
- B 战斗 HUD 底部中多了商店/任务两个圆钮（骨架外增项），实现时可保留为高频入口或收回菜单，待定版时一并定。
- A 战斗 HUD 封印核血条为紫色、B 为绿色；若选 B，建议核血条改紫以呼应紫晶焦点（B 商店图左上小条同此议）。
