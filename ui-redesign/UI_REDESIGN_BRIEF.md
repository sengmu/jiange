# 剑阁手游 UI 重制 + 移动优化 · 美术设计简报 v1（2026-11-15 用户令）

用户原令：「做手游移动设备优化，ui也要重新制作，先使用codex生成美术设计图」
本轮只出美术设计图给用户挑方向，不写游戏代码、不改 main.gd。

## 游戏与画面基线（必须贴合，不许另起炉灶）
- 游戏：《守卫剑阁·纵横天下》独立手游复刻，只复刻机制、全原创素材，不用暴雪/原图素材。
- 类型：三国题材横屏防守 RPG（守封印核、20 波、英雄+建塔+商店+任务）。
- 3D 战场既定美术：黄昏暖橙天光 + 冷灰绿草地 + 石墙门楼 + 蜀汉红旗 + 紫色封印核水晶（全场焦点）+ 紫色裂隙。设计图里的战场背景必须延续这个世界：南向北俯视战场、中央土路、左侧基地紫晶、红旗，不要换成科幻/欧美奇幻/日式二次元世界。
- 参考图（Codex 输入图）：现行触控 HUD 全场图 controls_a_overview.png（看现布局与战场）、现行选将面板 screen_touch_01_select.png（看现痛点）。

## 现行 UI 痛点（设计必须逐条解决）
1. 全是 Godot 默认灰黑半透明矩形 + 纯文字，没有材质、没有三国身份、没有图标体系。
2. 左上状态面板又大又挤：标题/封印核血条/波次/金币/帧率/英雄属性全堆一坨，压住新城等画面牌位。
3. 选将是 22 个纯文字按钮网格，无头像、无职业/技能图标、无属性可视化，锁定英雄只靠「（锁）」二字。
4. 商店面板是纯黑小框纯文字列表，无物品图标、无品质色、无大购买键，手指难点。
5. 底部栏拥挤：技能/重开/重置视角/修复/画质/帮助长句全平铺，触控归类虽已分右列/中条，视觉仍是临时拼凑。
6. 帮助文案是桌面口径长句（右键/滚轮），手游图里不许出现。

## 移动设备优化要求（体现在设计上）
- 目标设备：Solana Seeker 安卓手机横屏，设计画布横屏 16:9（1920×864 观感），安全区内缩，避开挖孔/圆角。
- 拇指区：左下虚拟摇杆（半透明、按下才显强），右下技能大圆钮集群（主技能 ≥118px 逻辑直径 + 修复/下一波小圆钮竖列），其余高频操作不放屏幕顶部中央。
- 触控热区：所有可点元素 ≥64px，按钮间距 ≥10px；关闭键大且固定右上。
- 信息层级：战斗中只留「当下决策需要」的数——封印核血条（细条+数字）、波次进度、金币、英雄头像+血条+等级、技能冷却；帧率/画质收进系统菜单，不常驻。
- 面板形态：选将/商店/任务用居中大卡或底部上滑大面板，内部卡片化、图标化、可滚动；一次只主导一个面板，不与 HUD 底层文字打架（底层 HUD 面板打开时自动隐藏/变暗）。
- 可读性：强光户外可读——关键数字大字号、高对比描边/底衬，禁止细灰字压在复杂 3D 画面上无底衬。
- 性能暗示：UI 用九宫格面板+图标图集的轻量画法即可实现，设计不要依赖全屏实时模糊/复杂粒子 UI 动效（移动端跑不起）；动效只许边框流光、冷却扫层这类廉价效果。

## 本轮交付（Codex 生图，共 4 张 PNG，存 ui-redesign/v1/）
同一功能布局骨架、两种皮肤方向对照（用户挑皮肤，不被布局差异干扰）：
布局骨架（战斗 HUD）：顶部细条（左：封印核血条+波次；中：事件横幅位；右：小地图+金币+菜单钮）/ 左下摇杆 / 右下技能集群 / 底部中：6 格背包细条 / 左侧中：英雄头像卡（头像+血+等级+经验细条）。

1. `A_battle_hud.png` — 方向 A「青铜墨金·三国战卷」战斗 HUD：深墨黑+古铜金边框、绢帛/漆器质感、蜀红点缀、紫晶辉光呼应封印核；气质沉稳厚重、策略感强。
2. `A_hero_select.png` — 方向 A 选将界面：22 英雄卡片网格（头像占位肖像、名、主属性图标、技能图标、锁定卡呈暗色+锁纹），底部详情条（选中英雄大头像+属性+技能说明+「开始守城」金钮），口令输入收成小入口。
3. `B_battle_hud.png` — 方向 B「明玉暖陶·清爽手游」战斗 HUD：奶白厚圆角面板+暖陶土/草绿/天蓝配色（呼应黄昏战场但更明亮）、图标圆润饱满；气质清爽亲和、手游感强、可读性优先。
4. `B_shop_panel.png` — 方向 B 商店面板（以一级装备店为例）：物品卡片行（武器图标+名+属性增量绿字+金价+大「购买」钮）、顶部店名牌匾+金币余额+背包格数、品质色边（白/绿/蓝/紫）、关闭大钮。

共同要求：
- 每张图必须是「像真手游截图」的完整界面设计图：战场背景真实延续参考图世界，UI 完整成套，不是零散组件拼贴、不是线框图。
- 中文标签只用短词大字（如 封印核、金币、残影剑、开始守城、购买），字要少而大；长说明不入画（最终实现时在 Godot 里排字，设计图定的是版式/材质/配色/图标语言）。
- 不出现桌面词汇（右键/滚轮/鼠标），不出现英文与中文混排长句。
- 图标体系成套：金币、波次、血条、技能、背包、任务、画质/系统等图标风格在 A/B 各自内部统一。

## 附带文字规格（Codex 同时写 ui-redesign/v1/SPEC.md）
两种方向各写：主色/辅色 HEX、面板材质一句话、字体层级（标题/数字/正文相对大小）、关键控件尺寸（技能钮/背包格/卡片）、与战场配色的呼应点、落地 Godot 时的九宫格/图集切分建议、移动性能注意（避免的效果）。
